📅 통독 일정
일정을 바꿔도 장별 읽기 기록은 유지됩니다.
읽기 순서
평소에는 비워두세요 — 전체 기간에 연속으로 균등 배분됩니다.
읽기가 밀려 목표가 필요할 때만 날짜를 지정하면, 그날까지 1단계를 마치도록 재배분되고 나머지는 최종 만료일에 맞춰 자동 조절됩니다.
일정에 포함할 날
공휴일 자동 갱신 (2028년 이후)
2026~2027년 공휴일은 내장되어 있습니다. 그 이후 연도가 일정에 포함되면 Google Calendar 공휴일 정보를 가져옵니다. Google Cloud에서 Calendar API를 사용 설정하고 API 키(HTTP 리퍼러 제한 권장)를 입력하세요.
공휴일 수동 보정
자동 데이터가 틀렸을 때 직접 고칩니다. 날짜를 고르고 [휴일 추가] 또는 [평일로 변경]을 누르세요.
🔔 알림
읽기 알림
선택한 시간에 오늘 분량이 남아 있으면 알림을 보냅니다.
알림을 받으려면 먼저 권한을 허용해 주세요.
알림 받을 시간 (여러 개 선택 가능)
알림 테스트 (5초 후 발송)
누른 뒤 홈 화면으로 나가세요. 앱 화면을 보고 있는 동안에는 안드로이드가 팝업을 생략하고 상단바에만 표시합니다.
📢 알림이 화면에 팝업으로 안 뜬다면
① 앱을 보고 있는 동안에는 안드로이드가 팝업을 생략합니다 — 테스트 버튼을 누르고 홈 화면으로 나가서 확인하세요.
② 그래도 안 뜨면: 알림을 길게 누르기 → ⚙️ → "알림 팝업" 체크 확인, 알림 유형을 "소리 및 팝업"으로
③ 방해금지 모드가 켜져 있으면 팝업이 표시되지 않습니다
🎧 낭독 음원
음원을 휴대폰에 저장
MP3 낭독 파일을 휴대폰에 저장해두면 인터넷 없이 재생됩니다.
권장: 폰의 내 파일에서 female / male 폴더를 각각 길게 눌러 → 압축(ZIP)한 뒤, 아래 버튼으로 ZIP 파일 1개를 선택하세요. (mp3 여러 개를 직접 선택해도 되지만 기기에 따라 500개 제한이 있습니다)
📙 대역 성경 함께 보기 (쉬운성경 · NIV · NKJV)
쉬운성경.json / NIV.json / NKJV.json 파일을 가져오면(여러 개 동시 선택 가능) 읽어주기 화면에서 역본을 선택해 절을 누르거나 [전체] 버튼으로 함께 볼 수 있습니다. 파일은 이 기기에만 저장됩니다.
📖 장 개요·분석 가져오기
장별 분석 JSON 파일을 가져오면 읽기 화면 [📖 개요]에서 전체 화면 분석으로 볼 수 있습니다. 여러 파일을 올리면 장 단위로 누적·갱신됩니다.
📱 읽는 동안 화면 항상 켜기
