# 말씀의 여정 — 성경 통독 (설정형 앱)

성경 66권 1,189장 전체를 다루는 **설정형** 1독 체크 PWA입니다. (남색 아이콘)
"말씀의 여정"(1독 앱)의 모든 기능을 계승하며, 일정을 직접 설계할 수 있습니다.
두 앱은 나란히 설치해 사용할 수 있고 기록은 서로 분리됩니다.

## 통독 일정 설정 (설정 탭 → 📅 통독 일정)

- **시작일 / 최종 만료일** 지정, **구약 먼저 / 신약 먼저** 선택
- **1단계 만료일 (선택)**: 평소에는 비워두면 전체 기간에 **연속 균등 배분**.
  읽기가 밀려 강제 목표가 필요할 때만 지정 — 그날까지 1단계를 마치도록 재배분되고
  나머지는 최종 만료일에 맞춰 자동 조절. "지정 해제"로 복귀
- **일정에 포함할 날**: 토 / 일 / 공휴일 각각 켜고 끔 (기본: 모두 제외)
- 일정 변경 시 장별 기록 유지, 기간 부족 시 이전 일정으로 자동 복원
- 하루 분량: 개역한글판 장별 **글자수 균등 배분** (1독 앱과 동일 정책)

## 공휴일 처리 (3단계)

1. **내장**: 2026~2027 전체(설·추석 연휴, 대체공휴일, 노동절·제헌절) + 검증된 2028 설날(1/26~28)
2. **자동 갱신**: 2028년 이후 일정 적용 시 Google Calendar 대한민국 공휴일에서
   해당 연도를 받아 캐시(공휴일·명절만). Calendar API 키 필요 — 발급·제한 방법은
   「음원제작_공휴일키_안내서.docx」 2부 참고. "공휴일 갱신"으로 임시공휴일 반영
3. **수동 보정**: 자동 데이터 오류(구글 음력 하루 오차 등)를 [휴일 추가] / [평일로 변경]으로
   직접 수정. 보정 내역은 갱신과 무관하게 유지

## 성취 시스템 (설정 탭 → 🏆 나의 기록)

- **하루 완료 축하**: 폭죽 + 진동 + 응원 문구
- **레벨**: 누적 6만 자마다 레벨 업(진행 바), **연속 기록**: 현재 🔥 / 역대 최고
- **배지**(획득 시 전체 화면 축하): 책 완독 66종 · 진행률 10%🌱 25%🌿 50%🌳 75%⛰️ 100%👑 ·
  7일🔥/30일💎 연속 · 🗓️ 월 개근

## 계승·공통 기능

- 오늘 읽기: 장별 체크 + 드래그 연속 체크, 진행 링, 분량 요약(장·절·자),
  여정 리본(선택한 읽기 순서 반영), 밀린 분량·쉬는 날 안내
- 전체 일정: 읽는 날만 표시, 오늘 위치 자동 스크롤 + 플로팅 버튼
- 알림: 오후 12:40/10:00/10:30/11:00 다중 선택, 완료·쉬는 날 미발송, 백그라운드 확인,
  테스트 5초 후 발송
- 읽어주기: 2줄 헤더(제목 온전 표시), 남/여 MP3(폰 저장→웹→TTS 순), 절 하이라이트,
  배속, 자동 체크·연속 재생
- **쉬운성경 함께 보기**: 쉬운성경.json 가져오기(기기에만 저장) 후 절 탭 또는
  [쉬운성경] 버튼으로 테라코타색 박스 표시
- **화면 켜짐 유지 설정**: 읽는 동안 항상 켜기(기본) ↔ 재생 중에만
- **기기 간 동기화**: GitHub 토큰(gist 권한) 하나로 폰↔태블릿 자동 공유
  (앱 열 때·화면 복귀 시 수신, 체크 20초 후 송신, 체크/해제는 최신 동작 승리 병합,
  배지 합산·일정은 최신 수정본) + 파일 내보내기/가져오기
- 세로/가로 화면 모두 지원 (태블릿 최적화)

## 배포

1독 앱과 **같은 계정의 별도 저장소**(예: bible2)에 업로드 → Pages 활성화 →
`https://아이디.github.io/bible2/` → 홈 화면에 추가.
같은 도메인이므로 폰 저장 음원·쉬운성경(IndexedDB)은 두 앱이 공유 — 한 번만 가져오면 됨.
