# 말씀의 여정 — 성경 통독 (설정형 앱)

성경 66권 1,189장 전체를 다루는 **설정형** 1독 체크 PWA입니다.
"말씀의 여정"(1독 앱)의 모든 기능을 계승하면서, 일정을 직접 설계할 수 있습니다.
남색 아이콘으로 구분되며, 1독 앱과 나란히 설치해 사용할 수 있습니다.

## 1독 앱과의 차이 요약

| 항목 | 1독 앱 (초록) | 통독 앱 (남색) |
|---|---|---|
| 범위 | 시편 28편~계시록 (684장) | 창세기~계시록 전체 (1,189장) |
| 일정 | 고정 (구약 9/11, 신약 11/30) | 시작일·만료일·순서·쉬는 날 직접 설정 |
| 공휴일 | 2026년 8~11월 내장 | 2026~2027 내장 + API 자동 갱신 + 수동 보정 |
| 성취 | — | 레벨·연속 기록·배지·폭죽 축하 |
| 기록 저장 키 | btr-* | btr2-* (서로 간섭 없음) |

## 통독 일정 설정 (설정 탭 → 📅 통독 일정)

- **시작일 / 최종 만료일**: 원하는 기간 지정
- **읽기 순서**: 구약 먼저 / 신약 먼저
- **1단계 만료일 (선택)**: 평소에는 비워두면 전체 기간에 **연속 균등 배분**.
  읽기가 밀려 강제 목표가 필요할 때만 날짜를 지정 — 그날까지 1단계(구약 또는 신약)를
  마치도록 재배분되고, 나머지는 최종 만료일에 맞춰 자동 조절. "지정 해제"로 복귀.
- **일정에 포함할 날**: 토요일 / 일요일 / 공휴일을 각각 켜고 끔 (기본: 모두 제외)
- 일정을 바꿔도 장별 읽기 기록은 유지되며, 기간이 부족하면 이전 일정으로 자동 복원
- 하루 분량 정책은 1독 앱과 동일: **개역한글판 장별 글자수 균등 배분**

## 공휴일 처리

- **내장**: 2026~2027년 전체(설·추석 연휴, 대체공휴일, 노동절·제헌절 포함)
  + 검증된 2028년 설날(1/26~28)
- **자동 갱신 (2028년 이후)**: 일정이 내장 범위를 넘으면 Google Calendar의
  대한민국 공휴일에서 해당 연도를 받아와 기기에 캐시 (공휴일·명절만, 기념일 제외).
  Google Cloud에서 **Calendar API** 사용 설정 후 API 키(HTTP 리퍼러를
  `https://아이디.github.io/*` 로 제한 권장)를 입력하면 동작.
  "공휴일 갱신" 버튼으로 임시공휴일 반영 가능.
- **수동 보정**: 자동 데이터가 틀린 날(예: 구글의 음력 하루 오차)을
  [휴일 추가] / [평일로 변경]으로 직접 고침. 보정 내역은 갱신과 무관하게 유지.

## 성취 시스템 (설정 탭 → 🏆 나의 기록)

- **하루 완료 축하**: 오늘 분량을 다 채우면 폭죽 + 진동 + 응원 문구
- **레벨**: 누적 읽은 글자수 6만 자마다 레벨 업, 진행 바 표시
- **연속 기록**: 읽는 날 기준 현재 연속 완료 🔥 / 역대 최고
- **배지** (획득 시 전체 화면 축하 + 폭죽):
  - 책 완독 66종 (예: 📖 창세기 완독)
  - 진행률 마일스톤: 10%🌱 25%🌿 50%🌳 75%⛰️ 100%👑
  - 연속: 7일 🔥 / 30일 💎
  - 🗓️ 월 개근: 그 달의 읽기 일정을 하루도 빠짐없이 완료

## 계승된 기능 (1독 앱과 동일)
- **쉬운성경 함께 보기**: 설정에서 쉬운성경.json을 가져오면(기기에만 저장, 공개 배포 금지)
  읽어주기 화면에서 절을 누르거나 [쉬운성경] 버튼으로 쉬운 번역을 함께 표시


- 장별 체크 + 드래그 연속 체크, 진행 링, 오늘 분량 요약(장·절·글자수)
- 여정 리본(책 눈금·오늘 목표 마커 — 선택한 읽기 순서 반영), 밀린 분량 안내, 쉬는 날 배너
- 전체 일정(읽는 날만 표시, 오늘 위치 자동 스크롤 + 플로팅 버튼)
- 다중 알림(12:40/22:00/22:30/23:00, 완료·쉬는 날엔 미발송, 백그라운드 확인)
- 읽어주기: 남/여 MP3(폰 저장 → 웹 → 기기 TTS 순), 절 하이라이트, 배속,
  자동 체크·연속 재생, 화면 꺼짐 방지, 음원 폰 저장 관리

## 배포

1독 앱과 **같은 계정의 별도 저장소**(예: bible2)에 이 폴더 전체 업로드 →
Pages 활성화 → `https://아이디.github.io/bible2/` → 홈 화면에 추가.
같은 github.io 도메인이므로 폰에 저장한 낭독 음원(IndexedDB)은 두 앱이 공유되어
한 번만 가져오면 됩니다.

## 낭독 음원

- 파일명 규칙은 1독 앱과 동일 (`audio/female|male/책id-장.mp3`)
- **기존에 생성한 시편 28편~계시록 음원을 그대로 재사용** 가능
- 창세기~욥기·시편 1~27(505장)은 이 폴더의 krv.json(전체판)으로 추가 생성:
  ```
  python tts_generate.py --key 키 --voice ko-KR-Chirp3-HD-Kore --out audio/female
  python tts_generate.py --key 키 --voice ko-KR-Chirp3-HD-Orus --out audio/male
  ```
  기존 파일은 건너뛰므로 부족한 장만 생성됩니다 (추가분 음성당 약 93만 자 —
  같은 달에 기존 생성분과 합치면 무료 한도 초과분은 크레딧에서 차감).
