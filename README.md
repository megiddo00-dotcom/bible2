# 말씀의 여정 — 성경 통독 (설정형)

66권 1,189장 전체를 다루는 설정형 성경 1독 체크 PWA입니다.
"말씀의 여정"(1독 앱)의 모든 기능을 계승하며, 일정만 설정형으로 바뀌었습니다.

## 1독 앱과의 차이
- 시작일·최종 만료일을 직접 설정 (설정 탭 → 통독 일정 설정)
- 구약 먼저 / 신약 먼저 선택
- 1단계(구약 또는 신약) 만료일 조정 가능 — 조정하면 나머지가 최종 만료일에 맞춰 자동 재배분
- 토요일 / 일요일 / 공휴일을 각각 일정에 포함할지 선택 (공휴일 데이터: 2026~2027)
- 하루 분량은 동일하게 개역한글 글자수 기준 균등 배분

## 배포
1독 앱과 같은 계정의 **별도 저장소**(예: bible2)에 이 폴더 전체를 올리고 GitHub Pages를 켜면
두 앱을 나란히 설치해 쓸 수 있습니다. 읽기 기록·설정은 서로 분리되어 있습니다.

## 낭독 음원
- 파일명 규칙은 1독 앱과 동일: audio/female|male/책id-장.mp3
- 기존에 생성한 시편28~계시록 음원을 그대로 재사용할 수 있습니다.
- 창세기~욥기·시편1~27은 이 폴더의 krv.json(전체판)으로 추가 생성:
  `python tts_generate.py --key 키 --voice ko-KR-Chirp3-HD-Kore --out audio/female`
  (기존 파일은 건너뛰므로 부족한 장만 생성됩니다. 추가분은 음성당 약 90만 자)
- 폰에 저장(설정 탭 → 낭독 음원 관리)하는 방식은 같은 도메인이면 1독 앱과 저장소를 공유하므로
  한 번만 가져오면 두 앱 모두에서 사용됩니다.

읽기 기록은 브라우저에만 저장되며 서버로 전송되지 않습니다.
